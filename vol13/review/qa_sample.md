# Vol 13 — independent sample check (English vs Kannada)

- Date: 2026-11-27
- Branch: `claude/vol13` (read-only check; this file is the only one written)
- Files: E = `vol13/Rigveda_Samhita_Vol13_English_Translation.md`, K = `vol13/Rigveda_Samhita_Vol13_Kannada_Text.md`
- Method: for each page the English between `### Printed p. N` and the next page heading was read in full side by side with the Kannada between `<!-- printed N -->` and the next mark. Checked: (1) numbers and references (ṛk, sūkta, Nirukta, Pāṇini, Brāhmaṇa, Saṃhitā numbers); (2) names, technical terms, quotations; (3) negations, attribution, who does what to whom; (4) omissions and additions. Also: announced quotations really follow; Pratipadārtha headwords (meaning present, no Kannada headword); grammar sections only for sūtra numbers and missing entries. Saṃhitā, Pada and Sāyaṇa blocks were checked only for being the right ones in the right place. Where a page starts or ends mid-sentence, the neighbouring page was read too, to see that nothing fell out at the boundary. The rows of `vol13/review/notes.tsv` for these pages were consulted so that places already marked **NOTE** are not reported as new.
- Pages (24): (a) evenly spread 1, 60, 120, 179, 239, 299, 358, 418, 478, 537, 597, 657; (b) Special Topics 17, 33, 81, 91, 125, 128, 135, 142, 174, 201, 215, 228.
