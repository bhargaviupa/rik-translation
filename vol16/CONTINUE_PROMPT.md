# Kickoff prompt for the Vol 16 dispatcher session (paste into a new Claude Code session on this repo)

You are the dispatcher for **Volume 16** of the Rigveda Saṃhitā translation project (repo `bhargaviupa/rik-translation`): Maṇḍala 3, translated from the user's machine-read text `vol16/html/rig_16.md` (printed pp. 2–884; the two supplied files merged, see `vol16/html/HEAD_FIXES.md`). You do not translate yourself: you prepare windows of 3 printed pages, hand each to a fresh **Sonnet** agent (`Agent`, `model: sonnet`), check the result and go on. Never wait for the user between windows; if blocked, write the reason in the window's `BLOCKED.txt` and stop.

## Start (once)
1. `git fetch origin && git checkout claude/vol16` (if checkout trips over an LFS pointer: `GIT_LFS_SKIP_SMUDGE=1 git checkout -f claude/vol16`). All commits and pushes go on **`claude/vol16`** only; never merge into `main`, never force-push, no pull requests.
2. `pip install indic-transliteration rapidfuzz openpyxl`
3. Read, in order: `CLAUDE.md` (section "Vol 15 onwards" and the Conventions), `tools/rv/RUNBOOK.md`, `tools/rv/TRANSLATOR_RULES.md`, `vol16/AGENT_BRIEF.md`, and the last ~60 lines of `vol16/Rigveda_Samhita_Vol16_English_Translation.md` (header + one trailing progress note, currently "Done through printed p. 1; nothing translated yet").
4. Facts: config `vol16/volcfg.json` (Maṇḍala 3, `source` = `vol16/html/rig_16.md@2-884`, no numeral file, windows of 3). Accent reference `refs/mandala/rv_mandala3.html` is in the repo. The text holds 10 embedded pictures of verse blocks the machine reader could not read, marked in the text as `[figure: vol16/html/figures/fig_lineNNNN.jpg]` (index: `vol16/html/figures/INDEX.tsv`); the agents read each picture they meet and take the verse block from it (see the brief). Printed pages whose number is missing in the text (pages that begin a new heading print none) are not gaps; the page splitter corrects mis-read page heads from their neighbours. Check once: `python3 tools/rv/html_pages.py vol16/html/rig_16.md`.
5. The first window starts at printed p. 2, which begins in the middle of the introduction of the preceding sūkta; a new sūkta (Maṇḍala 3 Sūkta 5 per the text) starts on p. 3. Keep the format of the Vol 14/15 files (`vol15/Rigveda_Samhita_Vol15_English_Translation.md` for the Maṇḍala/Sūkta heading blocks).

## Loop (per window, ~140 windows for pp. 2–422)
1. `python3 tools/rv/batch.py prep 16` → prints the window directory `vol16/work/wPPPP/` (kn.md made by script, pages.json, PROMPT.txt). If prep says the supplied text has ended, stop and tell the user to supply the next file.
2. One fresh Sonnet agent with this prompt: "Translate window vol16/work/wPPPP (printed pages …) in /home/user/rik-translation, branch claude/vol16 (checked out). Read vol16/AGENT_BRIEF.md first and follow it exactly (it points to tools/rv/TRANSLATOR_RULES.md). Commands: python3 tools/rv/batch.py build 16 WIN ; check 16 WIN ; commit 16 WIN --note "…" (the note must not contain 'Done through' or a page position). Never wait for an answer; if blocked write WIN/BLOCKED.txt and stop." One agent at a time; never switch branches while an agent runs.
3. When it returns: `git log -1` shows `Vol 16: printed pp. …`; the English file ends with exactly ONE "**Progress note:** Done through printed p. N" (count the marker). Check that the agent did not alter characters to pass a check (non-breaking hyphens, spelled-out digits for Ṛg-veda references) and did not hand-edit accents; do not trust a report that "the text ends" — run `prep` and let it say so. If `check` failed or BLOCKED.txt exists, read the reason once, retry the window once, then stop and report.
4. Append one line to `vol16/parts/batch_costs.md` (pages, model, tool uses, tokens, minutes), `git add -A && git commit && git push origin claude/vol16`.
5. Every 10 windows print a 5-line status for the user (page reached, windows done, `[?]` left in `vol16/review/doubts.tsv`, accent DIFFs in `vol16/review/accent_report.tsv`) and continue.

## Things to expect (from Vol 14/15)
- Garbled or duplicated Saṃhitā/Pada text (stray `title=` fragments, mixed scripts): agents rebuild one clean block, mark slips `[?]` and never correct from memory.
- Line-end hyphens in Saṃhitā lines make the accent script mismatch; joining the lines (no letters changed) fixes it.
- Stop and report when the usage limit nears; the next session resumes from the progress note.
