# Vol 27 — independent QA sample 2 (English vs Kannada)

Date: 2026-11-26. Read-only check. Files compared:
- E = `vol27/Rigveda_Samhita_Vol27_English_Translation.md`
- K = `vol27/Rigveda_Samhita_Vol27_Kannada_Text.md`

Line numbers are those of the two files as they stand on this date.

**Method.** I split each file on its page marks (`### Printed p. N` / `<!-- printed N -->`). For each page I read the English and the Kannada side by side: the Gist against the Sāyaṇa block, the Pratipadārtha entry by entry, the Bhāvārtha, the printed English, the Special Topics / Pīṭhike / Anuvāda prose. A script compared every number on each page (Kannada digits converted, Sanskrit block lines left out). No page had a number missing or changed: the only differences were structural headings such as "Sūkta 6 (Maṇḍala 10)" and the "xxvii 33" signature marks. A second script scanned the English of each page for:
- foreign-script letters (Telugu, Tamil, Kannada, Gurmukhi, Gujarati);
- word-list lines without Devanagari;
- remark phrases ("as supplied", "[?]", "[sic]", "Kannada reads", "correction", running heads);
- the heading used for each Pīṭhike.

I did not compare Sanskrit blocks letter by letter.

I avoided pages near 20, 110, 200, 300, 400, 500, 590, 680, 770, 860, 930 and 985.

**Pages checked (27):**
- 12 at spread positions: 65, 155, 252, 350, 445, 557, 640, 725, 817, 895, 960, 990.
