Read CLAUDE.md and vol14/vol14_runbook.md first (conventions, 'Reading a page', 'Translator rules', 'Turn economy', last section on numeral files). Format model: the style of Rigveda_Samhita_Vol14_English_Translation.md (read its last ~60 lines and the opening of the current sūkta); for structure not yet shown, Rigveda_Samhita_Vol13_English_Translation.md lines 44–400. Page offset: printed = PDF − 20 from PDF 336 on (PDF 223 and 335 were duplicate scan pages); check the printed number on each page; if another duplicate/missing page occurs say so in the file and the note and keep numbering as printed; if a page edge is cut off mark lost text […] and supply nothing.

NUMERALS: run `python3 vol14/tools/numerals_for.py PDFPAGES` FIRST. It prints, per page, the reference/sūtra numerals read by another engine (reliable digits; separators and leading digits sometimes lost, two references can run together, a repeated digit can appear, e.g. '2-4-677' for 2-4-77; the raw words are noisy OCR — never use them as text; some pages have no rows; headers, Ṛk numerals and some references are not listed). While reading each strip compare every reference/sūtra number with the file: agree → write it, no zoom; differ → check that place once (a local 2x crop of the strip, or `python3 vol14/tools/page.py PDFPAGE /tmp/z --strip K --box X0 Y0 X1 Y1 --dpi 600`; zoom boxes are often off by a line or more — use tall generous boxes and check the crop shows the intended line); crop supports the file → file value; supports your reading → write yours and note 'file said X' in the progress note flags; undecided → `[?]`. Numerals the file lacks you read from the strip (digit key in CLAUDE.md: round open-loop = 2, hooked = 3, flat-footed = 7; the Kannada glyph that looks like ಜ is 5; calibrate with the running header) and flag when unzoomed and doubtful. Log every zoomed place and every `[?]` with `python3 vol14/tools/doubt.py PDFPAGE y0 y1 x0 x1 "ZOOMED, read: …"` (or "FILE DISAGREE: file X, read Y" / "UNDECIDED: …").

TOOLS/RULES: render each page with `python3 vol14/tools/page.py PDFPAGE /tmp/pg_PDFPAGE` and view EVERY strip with the Read tool, all strips of all pages in ONE message of parallel Read calls (no OCR for readings; never fill Sanskrit from memory; if an image view returns no image STOP and report). Write Devanagari + English yourself; IAST by script only: mark ALL inline Sanskrit with ⟦…⟧ (never type IAST by hand, including sūtra names) and run `python3 publish/tools/translit/add_iast.py` on your own chunk file only. Known script gaps: add_iast.py skips the IAST for a bhāṣya block directly followed by a `**Pratipadārtha.**` line and for a block right after which a `*Gist:*` line stands (put gist lines before the block or after its IAST line; put a temporary placeholder line between the bhāṣya block and the Pratipadārtha line, remove it afterwards); inside a blockquote it duplicates lines — write quoted English passages as plain paragraphs. Verify every Devanagari block in your chunk has its IAST line. Mark each printed page `### Printed p. N (PDF M)`. Append with `python3 vol14/tools/append_en.py "PROGRESS NOTE" < chunk.md` once per page (one trailing progress note naming printed page reached, sūkta/Ṛk position, any Ṛk left open, plus flags; keep the existing flags, never duplicate flag blocks; the script refuses if the file shrinks by more than 2000 characters — rebuild the note from the old flags if needed; if the note nears 15,000 characters move its oldest flags verbatim to a new vol14/review/flags_archive_*.md and leave a pointer line, combined with an append that adds at least as much text; never call append_en.py with --help). Do the batch in about 12 turns (parallel calls). If a Ṛk continues past your last page, leave it open and say so. Per Ṛk: Saṃhitā, Pada, Sāyaṇa bhāṣya (Devanagari + ≤25-word gist), Pratipadārtha, Bhāvārtha, printed English ([sic] for misprints), Special Topics, Vyākaraṇa-prakriyā (2–4-line note). At the end of a sūkta write the colophon/closing note as printed (three layers if Sanskrit; supply nothing not printed) and open the next sūkta with a heading block in the style of earlier openings. Edit no file besides the output file, vol14/review/doubts_v14.json and archive files.
