# Brief for the translator agent of one window of the Vol 14 experiment (pp. 501-766 from the supplied text)

Purpose: translate Vol 14 printed pp. 501-766 AGAIN, this time from the user's machine-read text, so that the result can be compared with the scan-based translation already in the repository. The experiment slot is called **Vol 99** in the tools (`batch.py ... 99 ...`); its files are under `vol99/`.

INDEPENDENCE RULE: do NOT open `Rigveda_Samhita_Vol14_English_Translation.md`, `vol14/Rigveda_Samhita_Vol14_Kannada_Text.md` or anything else under `vol14/work/` or `vol14/review/` (they hold the scan-based translation). For the format and style read only the last ~60 lines of `vol15/Rigveda_Samhita_Vol15_English_Translation.md` and of `vol99/Rigveda_Samhita_Vol99_English_Translation.md`.

1. Read `tools/rv/TRANSLATOR_RULES.md` (follow it exactly) and the window's `kn.md`.
2. Write `WIN/en.md` (Sanskrit blocks placed with `[[bN]]`, inline Sanskrit as `⟦Kannada⟧`; never type Devanagari/IAST), then `python3 tools/rv/batch.py build 99 WIN` and `... check 99 WIN` until PASS, then `... commit 99 WIN --note "…"` (the note must not contain "Done through" or a page position; `--max-doubts N` for the `[?]` you must leave; the limit counts kn.md and en.md together).
3. Pictures: kn.md may contain `[figure: vol14/html/figures/fig_lineNNNN.jpg]` (followed by the machine reader's garbled guess). The picture holds a Saṃhitā/Pada block the machine could not read. LOOK AT IT with the Read tool (zoom with PIL if a letter is unclear) and write the block into kn.md from the picture, letter by letter, Kannada script only (replace the garbled text of the same verse; join the Saṃhitā into the two lines of the reference verse; never complete from memory; unsettled letters get `[?]`; remove the figure line when used). Edits with `batch.py fix 99 WIN kn "OLD" "NEW"`.
5. Usual kn.md repairs (no letters changed): Pratipadārtha/Bhāvārtha/Special-Topics lines made into `> ` blocks → prose under the standard label; garbled labels → standard; line-end hyphens in Saṃhitā lines joined so the accent script matches; other-script letters inside Kannada lines → Kannada letter for letter. If the accent script reports DIFF because the supplied spelling differs from the reference, leave the line and report it.
6. Do NOT replace characters to pass a check. Page ranges with Latin digits that check flags may be written as a spelled phrase; Ṛg-veda/Nirukta numeric references keep their digits. Reproduce the printed English of each Ṛk as supplied; mark misprints [sic]; never silently correct. Never change a letter or number from memory; unsettled places become `[?]`.
7. Check that no Saṃhitā line in en_final.md has a doubled pluta digit or doubled accent mark, and no accent mark after the Ṛk number "॥ N ॥". Do not hand-edit accents.
8. Do not touch git except through `commit`. If blocked write WIN/BLOCKED.txt and stop. Final report (short): what was written, kn.md fixes, `[?]` places, accent DIFFs, oddities.
