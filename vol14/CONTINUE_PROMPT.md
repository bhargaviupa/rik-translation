## Accents (Nov 3 2026)
Saṃhitā lines of Maṇḍala 2 carry Vedic accent marks (॑ ॒ and the svarita digits ‘१॒’) transferred by `vol14/tools/accents.py` from the volunteer reference text `vol14/refs/rv_mandala2_accented.txt` (user-supplied; personal study use). Only marks are added (checked: stripping them gives back the printed text); IAST and Pada lines stay unaccented. The API runner applies it to each new chunk. Where our printed spelling differs from the reference beyond final -m/anusvāra style, the line is listed in `vol14/review/accent_ref_differences.tsv` for checking against the page (the print is kept).
