# Supplied numeral files (Vol 14)

The user supplies files here that give the numerals read from each page (references, sūtra numbers, header numerals, Ṛk/Varga/Anuvāka numbers). **Format and naming: to be filled in when the first files arrive** (nothing assumed). Translators (Sonnet) take numerals only from these files; no numeral zooming, no digit analysis. If the file for a page is missing or a place is marked unreadable: STOP and report / write `[?]`.
