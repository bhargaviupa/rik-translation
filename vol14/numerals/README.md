# Supplied numeral files (Vol 14)

The user supplies files here that give the numerals read from each page (references, sūtra numbers, header numerals, Ṛk/Varga/Anuvāka numbers). **Format and naming: to be filled in when the first files arrive** (nothing assumed). Translators (Sonnet) take numerals from these files as the default and verify each against the page strip; zoom only where they differ; the zoom decides; overrides are flagged 'file said X'. If the file for a page is missing or a place is marked unreadable: STOP and report / write `[?]`.
