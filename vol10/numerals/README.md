# Supplied numeral files (Vol 10)

`Rigveda_Clean_Numerals_10_1.xlsx` (447 rows) and `..._10_2.xlsx` (449 rows): one sheet "Clean Numerals", columns **Page Number** (page 1–100 within scan part N = `vol10/scans/10 Rigveda Samhitha Volume 10 N.pdf`), **Line Number**, **Extracted Pattern** (Kannada digits), **Equivalent English Numbers** (Arabic digits, `-` or `.` separated), **Raw Line Context** (OCR line, often garbled).
Global PDF page = Page Number + 100·(N−1); this equals the `(PDF g)` in the English file's `### Printed p. X (PDF g)` headings (checked: 75% of rows' numbers occur on exactly that page, <6% on ±1…3). Files cover only PDF 1–200 (up to Sūkta 124, printed p. ~179); parts 3–7 not supplied.
Many rows are not `[?]` places (the English already has the number, or the pattern is a Sūkta/page count). Tool: `vol10/tools/apply_numerals.py` (confirms/corrects/fills only flagged numeric references with an unambiguous match on the same page). Logs: `vol10/review/numerals_applied_v10.tsv`, `numerals_unmatched_v10.tsv (removed; see numerals_report_v10.tsv)`.
