[ಅ. ೫. ಅ. ೫. ವ. ೨೦ ] ಋಗ್ವೇದಸಂಹಿತಾ 401
ಇವುಗಳಿಗೆಲ್ಲಾ ಅಚಿ ನೋಡುತ್ತಾನೆ (ಅ. ವೇ. ೧೩-೧-೪೫). ಅವನು ದೂರದರ್ಶಿ, ಎಂದರೆ ಬಹುದೂರ ನೋಡಬಲ್ಲನು. (೭-೩೫-೮ ; ೧೦-೩೭-೧) ಸರ್ವದರ್ಶಿ (೧-೫೦-೨). ಎಲ್ಲ ಪ್ರಪಂಚದ ಗೂಢಚಾರಿ (೪-೧೩-೩) ಸ್ಥಾವರಜಂಗಮಾತ್ಮಕವಾದ ಪ್ರಪಂಚವನ್ನೂ, ಮಾನವರು ಮಾಡುವ ಒಳ್ಳೆಯ ಮತ್ತು ಕೆಟ್ಟಕೆಲಸಗಳನ್ನೂ ನೋಡುತ್ತಾನೆ. (೧-೫೦-೨ ; ೬-೫೧-೨ ; ೭-೬೦-೨ ; ೭-೬೧-೧ ; ೭-೬೩-೧, ೪). ಸೂರ್ಯನ ಉದಯದಿಂದ ಜಾಗೃತರಾಗಿ ಜನರು ತಮ್ಮ ಕೆಲಸಕಾರ್ಯಗಳಲ್ಲಿ ಪ್ರವೃತ್ತರಾಗುತ್ತಾರೆ. (೭-೬೩-೪). ಅವನು ಮನುಷ್ಯರೆಲ್ಲರನ್ನೂ ಎಚ್ಚರಗೊಳಿಸುತ್ತಾ ಉದಯಿಸುತ್ತಾನೆ. (೭-೬೩-೨,೩) ಚರಾಚರವಸ್ತುಗಳಿಗೆಲ್ಲಾ ಅವನೇ ಆತ್ಮ, ಅವನೇ ರಕ್ಷಕ (ಋ.ಸಂ. ೧-೧೧೫-೧; ೭-೬೦-೨) ಅವನ ರಥಕ್ಕೆ ಒಂದೇ ಕುದುರೆ (೭-೬೩-೨) ಅಥವಾ ಏಳು ಕುದುರೆಗಳಿವೆ (೫-೪೫-೯) ಅಥವಾ ಏಳುಹೆಣ್ಣು ಕುದುರೆಗಳಿವೆ. (ಹರಿತಃ) (೧-೫೦-೮, ೯ ; ೭-೬೦-೩) ಅಥವಾ ಏಳು ಶೀಘ್ರಗಾಮಿಗಳಾದ ಕುದುರೆಗಳಿವೆ.(೪-೧೩-೩)
ವರುಣನು ಸೂರ್ಯನಿಗೋಸ್ಕರ ಅವನು ಸಂಚರಿಸಬೇಕಾದ ಮಾರ್ಗವನ್ನು ಸಿದ್ಧಪಡಿಸುತ್ತಾನೆ (೧-೨೪-೮ ; ೭-೮೭-೧) ಅಥವಾ ಮಿತ್ರ, ವರುಣ ಮತ್ತು ಆರ್ಯಮರು ಮೂವರೂ ಸಿದ್ಧಪಡಿಸುತ್ತಾರೆ (೭-೬೦-೪). ಪೂಷಣನು ಅವನ ದೂತನು (೬-೫೮-೩). ಸೂರ್ಯನು ಉಷೋದೇವತೆಯ ಮಡಿಲಿನಿಂದ ಪ್ರಕಾಶಿಸುತ್ತಾ ಹೊರಹೊರಡುತ್ತಾನೆ. (೭-೬೩-೩). ಕೆಲವುಕಡೆ ಉಷೋದೇವತೆಯನ್ನು ಸೂರ್ಯನ ಪತ್ನಿಯೆಂದು ಹೇಳಿದೆ (೭-೭೫-೫).
ಸೂರ್ಯನು ಅದಿತಿಯ ಮಗನಾದುದರಿಂದ ಅವನಿಗೆ ಆದಿತ್ಯ ಅಥವಾ ಆದಿತ್ಯೇಯ ಎಂಬ ಹೆಸರು ಬಂದಿದೆ (೧-೫೦-೧೨ ; ೧-೮೯-೮ ; ೮-೯೦-೧೧ ; ೧೦-೮೮-೧೧) ಆದರೆ ಇವನೂ ಆದಿತ್ಯರೂ ಭಿನ್ನರು (೮-೩೫-೧೩, ೧೪). ದ್ಯುದೇವತೆಯು ಅವನ ಜನಕನು (೧೦-೩೭-೧) ಅವನು ದೇವತೆಗಳಿಂದ ಜನಿಸಿದವನು. ಸಾಗರದಲ್ಲಿ ಅಡಗಿದ್ದ ಅವನನ್ನು ದೇವತೆಗಳು ಮೇಲಕ್ಕೆ ಎತ್ತಿದರು (೧೦-೭೨-೭). ಅಗ್ನಿಯ ರೂಪಾಂತರವಾಗಿ ದೇವತೆಗಳು ಅವನನ್ನು ಆಕಾಶದಲ್ಲಿ ಸ್ಥಾಪಿಸಿದರು. (೧೦-೮೮-೧೧) ಅವನು ವಿರಾಟ್ರೂಪದ ಪುರುಷನ ನೇತ್ರದಿಂದ ಉದ್ಭವಿಸಿದನು (೧೦-೯೦-೧೩).
ನಾನಾದೇವತೆಗಳು ಪ್ರತ್ಯೇಕಪ್ರತ್ಯೇಕವಾಗಿ ಸೂರ್ಯನ ಉತ್ಪತ್ತಿಗೆ ಕಾರಣರೆಂದು ಹೇಳಿದೆ. ಇಂದ್ರನು ಅವನನ್ನು ಜನಿಸುವಂತೆ ಮಾಡಿ (೩-೩೧-೧೫) ಆಕಾಶದಲ್ಲಿ ಸ್ಥಾಪಿಸಿ ಅಲ್ಲಿ ಪ್ರಕಾಶಿಸುವಂತೆ ಮಾಡಿದನು (೨-೧೪-೩ ; ೮-೮೯-೨) ಇಂದ್ರಾವಿಷ್ಣುಗಳು ಅವನ ಜನಕರು (೮-೯೯-೪). ಬೆಳಕಿನೊಡನೆ ಕೂಡಿದ ಸೂರ್ಯನನ್ನು ಇಂದ್ರಸೋಮರು ಬೆಳೆಸಿದರು (೬-೭೨-೪). ಮಿತ್ರಾವರುಣರು ಅವನನ್ನು ಆಕಾಶದಲ್ಲಿ ಸ್ಥಾಪಿಸಿದನು (೫-೬೩-೭). ಸೂರ್ಯನಲ್ಲಿ ಪ್ರಕಾಶವು ಸೋಮನಿಂದ ಸ್ಥಾಪಿತವಾಯಿತು (೬-೪೪-೨೩ ; ೯-೯೬-೫). ಸೋಮನಿಂದಲೇ ಸೂರ್ಯನು ಜನಿಸಿದನು (೯-೯೬-೫ ; ೯-೧೧೦-೩). ಸೋಮದೇವತೆಯೇ ಸೂರ್ಯನನ್ನು ಪ್ರಕಾಶಿಸುವಂತೆ ಮಾಡಿದನು (೯-೩೭-೨) ಅಥವಾ ಆಕಾಶದಲ್ಲಿ ಇರುವಂತೆ ಮಾಡಿದನು (೯-೧೦೧-೨). ಸೂರ್ಯನ ಕಾಂತಿಯನ್ನು ಬಹಳಮೇಲೆ ಸ್ಥಾಪಿಸಿದ್ದೂ (೧೦-೩-೨) ಆಕಾಶಕ್ಕೆ ಏರುವಂತೆ ಮಾಡಿದುದೂ (೧೦-೧೫೬-೪) ಅಗ್ನಿಯೇ. ಸೃಷ್ಟಿಕರ್ತನಾದ ಧಾತೃವೇ ಸೂರ್ಯಚಂದ್ರರಿಬ್ಬರನ್ನೂ ರೂಪುಗೊಳಿಸಿದನು (೧೦-೧೯೦-೩). ಅಂಗಿರಸರ ಯಜ್ಞಕರ್ಮಗಳಿಂದ ಸೂರ್ಯನು ಆಕಾಶವನ್ನು ಏರಲು ಸಾಧ್ಯವಾಯಿತು (೧೦-೬೨-೩). ಸೂರ್ಯನ ಜನ್ಮಸಂಬಂಧವಾದ ಈ ಋಕ್ಕುಗಳಲ್ಲೆಲ್ಲಾ ಕಾಂತಿಯುಕ್ತವಾದ ಸೂರ್ಯಮಂಡಲವೇ ಸೂಚಿತವಾಗಿದೆ.
ಅನೇಕ ವಾಕ್ಯಗಳಲ್ಲಿ ಸೂರ್ಯನು ಅಂತರಿಕ್ಷದಲ್ಲಿ ಹಾರಾಡುತ್ತಿರುವ ಒಂದು ಪಕ್ಷಿ (೧೦-೧೪೬-೩, ೪) ಯೆಂದು ಭಾವಿಸಲ್ಪಟ್ಟಿದ್ದಾನೆ. ಅವನು ಪುಷ್ಪಪಾದ ಒಂದು ಪಕ್ಷಿ (೫-೪೭-೩) ಸೂರ್ಯನು ಹಾರುತ್ತಾನೆ. (೧-೫೦-೯) ಅವನನ್ನು ಹಾರುತ್ತಿರುವ ಗಿಡುಗನಿಗೆ ಹೋಲಿಸಿದೆ (೭-೬೩-೫) ಒಂದುಕಡೆ ಗಿಡುಗನೆಂದೇ ಕರೆದಿದೆ. (೫-೪೪-೧೧)
