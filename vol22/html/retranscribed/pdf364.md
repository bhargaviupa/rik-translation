338 ಸಾಯಣಭಾಷ್ಯಸಹಿತಾ [ಮಂ. ೭. ಅ. ೪. ಸೂ. ೫೬.]
ಗಳೊಡನೆ ಒಂದೊಂದು ಸೂಕ್ತದಲ್ಲಿಯೂ ಒಟ್ಟು ೪೩ ಸೂಕ್ತಗಳಲ್ಲಿ ಇವರು ಸ್ತುತರಾಗಿದ್ದಾರೆ. ಇವರನ್ನು ಗಣ ಅಥವಾ ಶರ್ಧ (೧-೩೭-೧) ಇತ್ಯಾದಿ ಶಬ್ದಗಳಿಂದಲೂ ಬಹುವಚನಪ್ರಯೋಗದಿಂದಲೂ ವರ್ಣಿಸಲಾಗಿದೆ. ಅವರು ರುದ್ರನ ಪುತ್ರರು. ಅನೇಕಕಡೆ ಅವರನ್ನು ರುದ್ರರೆಂದೇ ಕರೆಯಲಾಗಿದೆ (೧-೩೮-೪, ೫ ಇತ್ಯಾದಿ) ಕೆಲವುವೇಳೆ ಇವರಿಗೆ ರುದ್ರಿಯರೆಂದೂ (೧-೩೮-೨ ; ೨-೩೪-೧೦ ಇತ್ಯಾದಿ) ಹೆಸರಿದೆ. ಪೃಶ್ನಿಯ ಪುತ್ರರು (೨-೩೪-೨ ; ೫-೫೨-೧೬ ; ೫-೬೦-೫ ; ೬-೬೬-೩) ಪೃಶ್ನಿಮಾತರಃ (ಪೃಶ್ನಿಯೇ ತಾಯಿಯಾಗಿ ಉಳ್ಳವರು) ಎಂದೂ ಅನೇಕಸಲ ಕರೆದಿದೆ. (೧-೩೮-೧೦ ; ಅ. ವೇ. ೫-೨೧-೧೧. ಇತ್ಯಾದಿ) ಪೃಶ್ನಿ ಎಂಬ ಗೋವೇ (೫-೫೨-೧೬) ಅಥವಾ ಸಾಧಾರಣವಾದ ಗೋವೇ (೮-೯೪-೧ ಅವರ ಜನನಿಯು. ಅವರನ್ನು ಗೋಮಾತರಃ ಎಂದೂ ಕರೆದಿದೆ. (೧-೮೫-೩ ; ೮-೨೦-೮) ಈ ಗೋವು ಪ್ರಾಯಶಃ ಚಂಡಮಾರುತದ ನಾನಾವರ್ಣರಂಜಿತವಾದ ಮೇಘವಿರಬಹುದು. ದೊಡ್ಡದಾದ ಕೆಚ್ಚಲುಳ್ಳ ಗೋವುಗಳು ಉರಿಯುತ್ತಾ ಬರುತ್ತವೆ (೨-೩೪-೫) ಎಂಬಲ್ಲಿ ಅವು ಬಿರುಗಾಳಿಯು ಬೀಸುತ್ತಿರುವಾಗ ಮಿಂಚು, ಸಿಡಿಲುಗಳಿಂದಕೂಡಿದ ಮೇಘಗಳೇ ಆಗಿರಬೇಕು. ಪೃಶ್ನಿಯಿಂದ ಜನಿಸಿದಾಗ ಮರುತ್ತುಗಳನ್ನು ಅಗ್ನಿಗೆ ಹೋಲಿಸಿದೆ (೬-೬೬-೧, ೨, ೩) ಸಿಡಿಲಿನ ನಗುವಿನಿಂದ ಮರುತ್ತುಗಳು ಜನಿಸಿದರು. (೧-೨೩-೧೨) ಅಗ್ನಿಯು ಅವರಿಗೆ ರೂಪವನ್ನು ಕೊಟ್ಟನು ಅಥವಾ ಅವರನ್ನು ಪಡೆದನು (೬-೩-೮ ; ೧-೭೧-೮). ವಾಯುವು ಅವರನ್ನು ಅಂತರಿಕ್ಷದ ಯೋನಿಯಲ್ಲಿ ಇಟ್ಟನು (೧-೧೩೪-೪) ಮತ್ತು ಅವರು ಆಕಾಶದ ಪುತ್ರರು (೧೦-೬೬-೨) ಮತ್ತು ಆಕಾಶದ ವೀರರು. (೧-೬೪-೪ ; ೧-೧೨೨-೧ ; ೫-೫೪-೧೦) ಅಥವಾ ಆಕಾಶದ ಗಂಡುಗಳು (೩-೩೪-೧೩ ; ೫-೫೪-೬). ಒಂದು ಕಡೆ ಅವರಿಗೆ ಸಮುದ್ರವು ತಾಯಿ (ಸಮುದ್ರಮಾತರಃ) ಎಂದು ಹೇಳಿದೆ. (೧೦-೭೮-೬) ಬೇರೆ ಕೆಲವು ಸ್ಥಳಗಳಲ್ಲಿ ಆತ್ಮಯೋನಿಗಳು) ತಮ್ಮಿಂದ ತಾವೇ ಜನಿಸಿದವರು) ಎಂದೂ (೧-೧೬೭-೩ ; ೫-೫೨-೨) ಹೇಳಿದೆ.
ಅವರು ಸಹೋದರರಾದರೂ ಅವರಲ್ಲಿ ಜ್ಯೇಷ್ಠ, ಕನಿಷ್ಠ ಎಂಬ ವ್ಯತ್ಯಾಸವಿಲ್ಲ (೫-೫೯-೬ ; ೫-೬೦-೫) ಏಕೆಂದರೆ, ಅವರೆಲ್ಲರೂ ಸಮಾನವಯಸ್ಸಿನವರು (೧-೧೬೫-೧). ಅವರೆಲ್ಲಾ ಒಟ್ಟಿಗೆ ಬೆಳೆದವರು (೫-೫೬-೫ ; ೭-೫೬-೧) ಮತ್ತು ಒಂದೇವಿಧವಾದ ಮನಸ್ಸುಳ್ಳವರು (೮-೨೦-೧ ಮತ್ತು ೨೧). ಅವರಿಗೆಲ್ಲಾ ಒಂದೇ ಜನ್ಮಸ್ಥಾನ (೫-೫೫-೩) ಮತ್ತು ಒಂದೇ ವಾಸಸ್ಥಳ (೧-೧೬೫-೧ ; ೭-೫೬-೧) ಅವರು ಆಕಾಶದಲ್ಲಿಯೂ, ಭೂಮಿಯಲ್ಲಿಯೂ, ಸ್ವರ್ಗದಲ್ಲಿಯೂ ಬೆಳೆದರು (೫-೫೫-೨) ಅಥವಾ ಮೂರುಸ್ವರ್ಗದಲ್ಲಿ ಬೆಳೆದರು (೫-೬೦-೬). ಅವರು ಪರ್ವತವಾಸಿಗಳೆಂದೂ ಒಂದುಕಡೆ (೮-೯೪-೧, ೨) ಹೇಳಿದೆ.
ಇಂದ್ರಾಣಿಯು ಅವರಿಗೆ ಮಿತ್ರಳು. ಇಂದ್ರಾಣಿ (೧೦-೮೬-೯) ಮತ್ತು ಸರಸ್ವತಿಯೊಡನೆ (೭-೯೬-೨) ಕಲೆಯುತ್ತಾರೆ. ಅವರು ಈರೀತಿ ಬಾಂಧವ್ಯವಿಟ್ಟುಕೊಂಡಿರುವುದು ರೋದಸೀ (ದ್ಯಾವಾಪೃಥಿವೀ ಅಥವಾ ರುದ್ರಪತ್ನಿ) ಎಂಬ ದೇವತೆಯೊಡನೇಯೇ ಹೆಚ್ಚು. ಅವಳು ಅವರಿಗೆ ಸುಖಸಾಧನಗಳನ್ನು ಒದಗಿಸುತ್ತಾ ಅವರೊಡನೆ ರಥದಲ್ಲಿ ನಿಂತಿರುತ್ತಾಳೆ (೫-೫೬-೪) ಅಥವಾ ಪಾರ್ಶ್ವದಲ್ಲಿ ನಿಂತಿರುತ್ತಾಳೆ ೬-೬೬-೬). ಅವಳ ಹೆಸರು ಬರುವ [?] ಸ್ಥಳಗಳಲ್ಲಿಯೂ ಮರುದ್ದೇವತೆಗಳ ಸಹಿತವಾಗಿಯೇ ಇರುವುದು (೧-೧೬೭-೪, ೫). ಆದುದರಿಂದ ಅಶ್ವಿನೀದೇವತೆಗಳಿಗೆ ಸೂರ್ಯೆಯಂತೆ ಅವಳು ಅವರ ವಧುವೆಂದು ಪರಿಗಣಿತಳಾಗಿದ್ದಾಳೆ. ಇದರಿಂದಲೇ ಅವರಿಗೆ ಭದ್ರಜಾನಯಃ (ಸುಂದರಳಾದ ಭಾರ್ಯೆಯುಳ್ಳವರು (೫-೬೧-೪) ಎಂಬ ವಿಶೇಷಣವು. ಮತ್ತು ಅವರನ್ನು ವರರಿಗೆ (೫-೬೦-೪) ಅಥವಾ ಯುವಕರಾದ ಪ್ರಣಯಿಗಳಿಗೆ (೧೦-೭೮-೪) ಹೋಲಿಸಲಾಗಿದೆ.
