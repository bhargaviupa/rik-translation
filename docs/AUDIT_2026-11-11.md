# Per-volume audit (Nov 11 2026)

Method: every volume measured by one script on the best available copy (main for Vols 2–15; `claude/vol16-translate`; `claude/affectionate-faraday-2iv8y4` for Vol 17; `claude/sleepy-albattani-4sgt7p` for Vol 18; `claude/gallant-dijkstra-e9ze2x` for Vol 1's new Kannada file). Checks: page-heading sequence, sūkta set, Ṛk headings per sūkta against `refs/mandala` (exact for Vols 12, 14–18), Saṃhitā-label count against the reference (rough for legacy volumes), residue marks, foreign scripts, IAST coverage, Kannada companion, review files, `batch.py audit` where it runs. Counts come from finished commands. "Reference" = the accented Saṃhitā in `refs/mandala` (10,552 verses, matches its README).

Caveats: the legacy files use six different heading layouts, so Ṛk-level checks are not possible there. A printed Ṛk of four pādas counts as two reference verses (Vol 6 Sūktas 65–69 print "5 (10)"), so Saṃhitā-label counts differ from the reference for legitimate reasons in Vols 6–8.
