# Second pass of Volume 1 — prompt for a new session (Sonnet is enough)

You carry out the **second pass of Volume 1** of the Rigveda translation (repo `bhargaviupa/rik-translation`). Volume 1 is a legacy volume (made from page scans; REQUIREMENTS Part L, family L1). The supplied machine-read text of the whole volume now exists, and the decisions of Nov 21–24 2026 (DESIGN §14, REQUIREMENTS Draft 5) say what the second pass is. One session, one volume, one writer. You may start subagents (Sonnet) for page batches; you do not use the API and spend no money.

## The volume
- **Scope:** Pūrva-pīṭhikā, Sāyaṇa's Bhāṣya-bhūmikā and Maṇḍala 1 Sūktas 1–2: printed pp. 1–720; the first 605 pages are continuous prose (preface, introduction, the Bhūmikā chapters), the Ṛk layout starts at p. 606.
- **Supplied text:** Three supplied files in `vol1/html/`: `rig_1_1.md` (front matter and pp. 1–224), `rig_1_2.md` (pp. 225–572, converted from HTML on Nov 18), `rig_1_3.md` (pp. 575–720). The Kannada file in `vol1/kannada/` was made from the old HTML form and **must be made again from the three markdown files**.
- **English:** `vol1/Rigveda_Samhita_Vol1_English_Translation.md` and `vol1/Rigveda_Samhita_Vol1_Gaps_English_Translation.md` (printed pp. 95–167, 191–205, 261–283 and 288–295, inserted by `publish/vol1_clean.py`); about 291,000 words; about 120 `[?]`.
- **Prose volume.** There is no unit structure for continuous prose yet (REQUIREMENTS: not built). Work page by page; do not invent a unit scheme.
- **Known gaps:** printed pp. 17–24 are missing in the source; about 148 pages have no Sanskrit; about 256 Sanskrit citations were converted from transliteration unverified; the records disagree on which page ranges were skipped or translated later (pp. 95–167, 119–191, 215–229, 285–307, 312–319). List what the files really contain, page by page, before reading anything.
- **Uniform files for every volume come from Vol 1:** the portrait pages (p. 4 king, p. 5 guru), the thank-you page and the bibliography (p. 39 of the PDF, the base of the abbreviation list). Cut them out as picture files and list them in `vol1/review/uniform_files.md`; the user decides the directory (REQUIREMENTS F35). Do not move anything.
- **Sāyaṇa's Bhāṣya-bhūmikā** is Sanskrit prose that may not be in the Wikisource index (the index holds the Ṛks and their commentary; check its `other` pages). Report whether it is; do not fetch anything from the site.
- **Legacy conventions (`[?]`, bracketed remarks) stay.** The old re-check prompt (`vol1/CONTINUE_PROMPT_HTML.md`) said not to convert Vol 1 to `NOTE`; the user has not changed that (REQUIREMENTS F7, M6). Reuse its rules for settling `[?]`: numbers and references are taken from the supplied text; text from context; only a place the context does not decide stays `[?]`.

Read first: `CLAUDE.md`, `vol1/STATUS.md`, `docs/REQUIREMENTS.md` Parts B, I, J, K9, L, M, `docs/DESIGN.md` §14, `docs/LESSONS.md`, `docs/ERROR_KINDS.md` (the kind codes you will use). `pip install indic-transliteration rapidfuzz openpyxl`.

## Rules
1. **Supplied Kannada text:** it may be edited by this pass (REQUIREMENTS B1.6, decided Nov 23 2026), only where the intended reading is certain, every edit one row of `vol1/data/source_fixes.tsv` (place, as supplied, as corrected, reason, basis, who decided). Where it is not certain, the place stays and becomes a row of `vol1/review/second_pass/questions.tsv`.
2. **The Wikisource text (`refs/wikisource`, index `python3 tools/rv/ws_index.py build`; commands `get M.S[.R[.P]]`, `search`) is never edited, never compared per Ṛk and never flagged,** except the three known defects of REQUIREMENTS B5.6. It is the source of the Saṃhitā, the Pada and Sāyaṇa's bhāṣya. Do not visit the site.
3. **English:** repairs of the existing English are separate edits, each a line of `vol1/review/repair_log.md` (page, old → new, why, the finding it answers). Do not re-translate; change a sentence only where the Kannada shows it wrong. A change of reading that changes the meaning also changes the English that depends on it; say so in the log.
4. **No number where the print has none; no letter or number from memory or from another edition.** Reference numbers are never changed by hand; `python3 tools/rv/refs_apply.py 1` (preview) is the only way names of works change.
5. **Legacy conventions stay** (`[?]`, `[sic]`, bracketed remarks, `**GLOSS**` markers): inventory them, do not convert or remove them (REQUIREMENTS F7, M6) unless a rule above settles the place.
6. **No per-volume tools or prompts.** If you need a script, write it in `tools/rv/` taking the volume as an argument. Never print `RIK_API_KEY`; do not call the API.
7. **Git:** work on the branch this session was given; commit and push after every stage and every batch; never force-push; no pull request; no merge into `main` unless the user says so. Report only what finished commands showed; quote `git log -1` for every commit you claim.

## Stages (each ends with a short report to the user; stop after S0 and after the S2 pilot and wait)
**S0. Set-up and sieve (scripts, no model).** (a) Merge or list the supplied files; page map; missing pages; pages without a head (list, do not chase). (b) `python3 tools/rv/batch.py audit 1` if it runs for this volume (it may not: legacy), else report the invariants you could check. (c) Script checks, each printing what it compared: numbers and references of the English against the supplied text (`tools/rv/recheck.py`, `recheck_numbers.py`, `numerals.py`); abbreviations against `rv/references.tsv` (`refs_apply.py 1` preview only); letters of other scripts in the English and Kannada; inventory of `[?]`, `[sic]`, remarks, `**GLOSS**`; Sanskrit citations of the English against the supplied text. (d) Write the results to `vol1/review/second_pass/sieve.md` and show the user the table (page, counts, differences) **before any batch starts**: it tells how big S2 is.

**S1. Kannada book from the supplied text (A5).** Make `vol1/Rigveda_Samhita_Vol1_Kannada_Text.md` from the supplied files by the shared scripts (`tools/rv/html_to_kn.py`, `prose_kn.py` for prose pages): the text of the original page by page, page marks, no remarks of ours. Its Sanskrit blocks stay as supplied (they are not part of the English; the later build takes the Saṃhitā, Pada and bhāṣya from Wikisource). Edits to the supplied text go through `source_fixes.tsv` (rule 1).

**S2. Reading in page batches.** Pilot first: **10 printed pages from the middle of the volume**, then batches of about 30 pages, one fresh Sonnet subagent per batch, one batch at a time. Per page the agent reads the supplied Kannada against the English once and looks for, in this order: (R1) a number or reference missing, changed or supplied from memory; a name or term wrong; roles reversed; an addition the Kannada does not have; an omission inside a paragraph; a misprint silently put right; (R6) a Kannada word that is not a word, a name or term misread for a look-alike, vowel signs of the wrong script, a page-break sentence cut; (R3) a Sanskrit quotation inside the commentary that is not a word or not the text the English cites. It does not read the Saṃhitā, Pada or bhāṣya blocks. Every finding is one row of `vol1/review/second_pass/findings.tsv` with the columns `page, kind (a code of ERROR_KINDS), reader (R1|R3|R6), place (the words), as_found, proposed, basis, decision (applied|question), log`. **Decision rule:** a number or reference is taken from the supplied text (digits are what the machine reads best) unless the user's numeral file for that place says otherwise; a text place is changed only where the Kannada sentence, the grammar of the quotation or the gloss that follows it decides; otherwise `question`. Report the pilot: pages read, findings by kind, applied, questions, tokens used; show five applied repairs with old and new text. Wait for the user before the batches.

**S3. Repairs.** Apply the `applied` rows: English repairs to the English file and `repair_log.md`; Kannada source edits to the supplied file and `source_fixes.tsv`. Re-run the S0 checks and show the before and after counts.

**S4. Sāyaṇa-bhāṣya layers (checks only; no English of the bhāṣya yet).** List which Maṇḍala.Sūkta.Ṛk addresses the volume covers (from the Wikisource index) and check by count that every Ṛk of the volume's scope has its Saṃhitā, Pada and bhāṣya in the index, none missing, none twice (REQUIREMENTS D17); write the list to `vol1/review/second_pass/ws_coverage.tsv`. **Do not translate the bhāṣya**: that needs the user's decision on cost, model and the user's own second reading (REQUIREMENTS K4.3, F49).

**S5. Pictures.** `python3 tools/rv/figures_sheet.py 1 --pdf` gives the contact sheet (`vol1/review/Vol1_pictures.pdf`); report the cover pictures (pictures 1 and 2 of the first supplied file) and the pictures that hold text. Do not transcribe pictures that hold a verse (REQUIREMENTS B6.6).

**S6. Records.** Update `vol1/STATUS.md` (what was read, counts, what is open), tick the second pass for Vol 1 in `PUBLICATION_TODO.md` with the date, commit and push. List every open question of `questions.tsv` in a table for the user (HR1, HR2 of Part J).
