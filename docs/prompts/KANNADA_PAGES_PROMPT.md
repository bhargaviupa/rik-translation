## How (shared tools only; rule 7)
- Make **one** shared tool, `tools/rv/restore_page_marks.py N [--write]` (dry run by default), not per-volume scripts. Method: load the supplied pages with `tools/rv/html_pages.py` (`load_many`; the volume's sources are in `volN/volcfg.json` `source`, or the files of `volN/html/` for the older volumes without one; `tools/rv/check_page_markers.py` explains how page chunks are counted); for a page N that has text in the supplied text but no marker in the Kannada file, find the line of the Kannada file where page N's text begins (compare the first lines of the supplied page, normalised: no spaces, no `|।॥>*[]\#`) and insert `<!-- printed N -->` (plus the running-head line `*[…]*` as the other pages have it) **before that line, with a blank line around it**; where the page really is not in the supplied text, write `<!-- printed N: NOT IN THE SUPPLIED TEXT -->`; replace a stale gap mark by the real marker.
- **The tool refuses** to write if: after the run a marker is repeated or out of order; the number of Kannada letters and digits of the file changed (a marker adds none: compare the file with the markers and running heads removed, before and after); a line was moved or lost. Every insertion is a row of `volN/review/page_marks_restored.tsv` (page, line, how found) and a line in `volN/review/repair_log.md`.
- Never edit a letter or digit of the supplied text or of the Kannada text (CLAUDE.md rule 2). **Never touch an English file.** After restoring markers in a volume that has an English file, `check_page_markers.py N` will show the English `### Printed p. N` and the Kannada markers disagreeing (D21): **list the pages in the report; do not edit the English** (the user decides).
- Order: Vol 5 first (the biggest; 26 stale marks, so the tool is proved on a file where the text is certainly there), then 2, 6, 4, then the volumes of item 2 (start with Vol 23, 43 pages, and Vol 26), then item 3.
- After each volume: `python3 publish/marks_check.py N` needs a built HTML: `python3 publish/volbook.py N kan --html-only` first (about 20 seconds); every marker must be in the build and none lost. Rebuild the PDF of a volume you changed with `python3 publish/build_all.py N --kan` (1–2 minutes; `pip install weasyprint`, then `apt-get update && apt-get install -y fonts-lohit-deva fonts-lohit-knda fonts-noto-core`), commit it with the md; look at two pages of it as images (D14): a page with a restored marker (footer "Kannada edition p. N") and a neighbour.
- Update `PUBLICATION_TODO.md` (T25, T26, §1a notes: tick with the date, "Last updated"), `docs/LESSONS.md`, `volN/STATUS.md`. Quote counts only from commands you ran.
